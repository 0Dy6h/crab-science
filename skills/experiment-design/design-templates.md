## 样本量计算公式

### 1. 两组比较（t检验）

**公式：**

```
n = (Z_{α/2} + Z_β)² × 2σ² / δ²

其中：
- Z_{α/2}：显著性水平对应的标准正态分位数（α=0.05 双尾时为 1.96）
- Z_β：功效对应的标准正态分位数（β=0.20 即 1-β=0.80 时为 0.84）
- σ：总体标准差（通常用预实验估计）
- δ：预期组间差异（最小有意义差异）
```

**效应量 (Cohen's d) 版本：**

```
n = (Z_{α/2} + Z_β)² × 2 / d²

d = δ / σ（小: 0.2, 中: 0.5, 大: 0.8）
```

### 2. 多组比较（单因素 ANOVA）

**公式：**

```
n = (Z_{α/2} + Z_β)² × σ² / (k × Δμ²)

其中：
- k：组数
- Δμ：最大组间均值差
```

**基于 f 效应量 (Cohen's f)：**

```
n = λ / f²

λ = (Z_{α/2} + Z_β)²（非中心参数近似）
f = σ_组间 / σ_组内（小: 0.1, 中: 0.25, 大: 0.4）
```

### 3. 配对设计（配对t检验）

```
n = (Z_{α/2} + Z_β)² × σ_d² / δ²

其中 σ_d 为差值的标准差
```

### 4. 比例比较（卡方检验）

```
n = (Z_{α/2} √(2p̄q̄) + Z_β √(p₁q₁ + p₂q₂))² / (p₁ - p₂)²

其中：
- p₁, p₂：两组预期比例
- p̄ = (p₁ + p₂) / 2
- q = 1 - p
```

### 5. 生存分析（Log-rank检验）

```
n_events = (Z_{α/2} + Z_β)² / (ln(HR))²

n = n_events / (1 - 生存比例)

其中 HR 为风险比
```

## 随机化方案模板

### 简单随机化
```python
import random
random.seed(42)  # 可复现
assignments = ['A' if random.random() < 0.5 else 'B' for _ in range(n)]
```

### 区组随机化
```python
import random
block_size = 4
blocks = []
for _ in range(n // block_size + 1):
    block = ['A'] * (block_size // 2) + ['B'] * (block_size // 2)
    random.shuffle(block)
    blocks.extend(block)
```

### 分层随机化
```python
# 按性别分层
for gender in ['M', 'F']:
    subset = [p for p in participants if p.gender == gender]
    random.shuffle(subset)
    # 在每层内随机分配
```

## 实验报告框架（CONSORT 简化版）

1. **标题**：随机化试验标识
2. **摘要**：结构化（背景-方法-结果-结论）
3. **引言**：背景与目的
4. **方法**：
   - 设计与随机化
   - 受试者（纳入/排除标准）
   - 干预措施
   - 结局指标（主要/次要）
   - 样本量计算
   - 统计分析
5. **结果**：
   - 受试者流程图
   - 基线特征
   - 主要分析结果
   - 次要分析结果
   - 不良事件
6. **讨论**：解释、局限性、推广性
