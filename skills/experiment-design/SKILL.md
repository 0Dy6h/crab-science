# Experiment Design Skill

## 概述

本技能指导你完成科研实验设计任务，包括：
- 研究假设构建与检验框架
- 自变量、因变量和控制变量设计
- 实验方案模板（对照、随机、盲法）
- 样本量计算与功效分析
- 统计分析规划（预设分析计划）

## 假设构建框架

### 1. 零假设与备择假设

```
H₀: 无效应/无差异
H₁: 有效应/有差异

示例：
H₀: 新药组与对照组的疗效无显著差异 (μ₁ = μ₂)
H₁: 新药组的疗效显著优于对照组 (μ₁ > μ₂)
```

### 2. 假设质量检查清单

- [ ] 可检验（可量化、可观测）
- [ ] 方向明确（单尾/双尾已指定）
- [ ] 基于理论或前人研究
- [ ] 变量操作化定义清晰

## 变量设计

### 变量类型

| 类型 | 定义 | 示例 |
|------|------|------|
| 自变量 (IV) | 研究者操纵的变量 | 药物剂量 (0mg, 50mg, 100mg) |
| 因变量 (DV) | 测量的结果变量 | 血压降低值 (mmHg) |
| 控制变量 | 保持恒定的变量 | 年龄段、性别比例 |
| 混杂变量 | 可能影响结果的变量 | 基线血压、体重 |

### 控制策略

1. **随机化**：随机分配消除系统偏差
2. **匹配**：按关键变量配对分组
3. **区组设计**：将相似实验单位分组
4. **协变量分析**：统计控制混杂变量

## 实验设计类型

### 1. 完全随机设计

```
适用：2 组或以上，组间比较
分组：随机分配
优点：简单
缺点：个体差异影响大
```

### 2. 随机区组设计

```
适用：存在已知混杂变量
方法：先按混杂变量分层，再随机分配
优点：控制混杂，提高功效
```

### 3. 重复测量设计

```
适用：同一受试者接受多种处理
方法：每个受试者经历所有条件
优点：减少个体差异，减少样本量
缺点：顺序效应（需平衡设计）
```

### 4. 析因设计

```
适用：同时研究多个自变量及其交互
方法：所有自变量水平组合
示例：2×3 析因（2 个药物 × 3 个剂量）
```

## 样本量计算

### 关键参数

- **效应量 (effect size)**：预期差异大小
- **显著性水平 (α)**：通常 0.05
- **功效 (1-β)**：通常 0.80 或 0.90
- **组数**：比较组数量

### 计算方法

详见附加文件 `design-templates.md` 中的样本量计算公式，
或使用 `sample-size.py` 脚本进行计算：

```bash
python3 sample-size.py --effect-size 0.5 --alpha 0.05 --power 0.8 --groups 2
```

## 统计分析规划

### 预设分析计划 (Pre-registered Analysis Plan)

1. **主要分析**：检验主假设的统计方法
2. **次要分析**：探索性分析
3. **敏感性分析**：检验结果稳健性
4. **缺失数据处理**：预设处理策略

### 方法选择流程

```
数据类型？
├── 连续型
│   ├── 2 组 → t 检验 / Mann-Whitney U
│   ├── >2 组 → ANOVA / Kruskal-Wallis
│   └── 重复测量 → 重复测量 ANOVA
├── 分类型
│   ├── 2×2 → 卡方检验 / Fisher 精确检验
│   └── 配对 → McNemar 检验
└── 生存数据
    └── Log-rank 检验 / Cox 回归
```

## 实验方案文档模板

```markdown
# 实验方案：{实验名称}

## 1. 研究背景与目的
- 背景：{相关文献综述}
- 目的：{研究目标}
- 假设：{H₀ 和 H₁}

## 2. 实验设计
- 设计类型：{完全随机/区组/重复测量/析因}
- 自变量：{IV 及水平}
- 因变量：{DV 及测量方法}
- 控制变量：{控制策略}

## 3. 样本
- 样本量：{计算依据}
- 纳入标准：{inclusion criteria}
- 排除标准：{exclusion criteria}
- 分组方法：{随机化方案}

## 4. 实验流程
1. {步骤 1}
2. {步骤 2}
3. {步骤 3}

## 5. 统计分析
- 主要分析：{方法}
- 显著性水平：α = {0.05}
- 功效：1-β = {0.80}
- 软件：{R/Python/SPSS}

## 6. 伦理考量
- 伦理审批：{IRB 编号}
- 知情同意：{流程}
- 风险控制：{措施}
```

## 注意事项

1. 实验设计应在数据收集前完成（预注册）
2. 样本量计算基于预实验或文献效应量
3. 主要分析应预先指定，避免 p-hacking
4. 随机化和盲法是减少偏差的关键
5. 记录所有偏离预设方案的情况
