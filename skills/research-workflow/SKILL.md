# Research Workflow Skill

## 概述

本技能指导你管理科研工作流的全生命周期，包括：
- 研究项目规划（选题→设计→执行→分析→撰写→发表）
- 里程碑与时间线管理
- 实验进度跟踪
- 团队协作与任务分配
- 风险管理与应急预案

## 科研项目全流程

### 阶段 1：选题与文献调研（2-4 周）

```
目标：确定研究方向，完成文献综述
├── 1.1 确定研究领域与关键词
├── 1.2 系统文献检索（使用 literature-search skill）
├── 1.3 文献筛选与精读（Top 20-30 篇）
├── 1.4 识别研究空白
├── 1.5 确定研究问题与假设
└── 1.6 撰写文献综述初稿
```

### 阶段 2：研究设计（1-2 周）

```
目标：完成实验方案设计
├── 2.1 构建假设（使用 experiment-design skill）
├── 2.2 变量设计（IV/DV/控制变量）
├── 2.3 样本量计算
├── 2.4 实验方案文档
├── 2.5 伦理审批申请
└── 2.6 预注册（如适用）
```

### 阶段 3：实验执行（4-12 周）

```
目标：完成数据收集
├── 3.1 实验材料准备
├── 3.2 预实验（pilot study）
├── 3.3 正式实验
├── 3.4 数据记录与管理
├── 3.5 质量控制
└── 3.6 实验日志更新
```

### 阶段 4：数据分析（2-4 周）

```
目标：完成统计分析
├── 4.1 数据清洗与预处理（使用 data-analysis skill）
├── 4.2 描述性统计
├── 4.3 推断性统计（按预设分析计划）
├── 4.4 敏感性分析
├── 4.5 数据可视化
└── 4.6 结果整理
```

### 阶段 5：论文撰写（4-8 周）

```
目标：完成论文初稿
├── 5.1 制定写作计划
├── 5.2 撰写各部分（使用 paper-writing skill）
│   ├── Methods（最先写）
│   ├── Results
│   ├── Introduction
│   ├── Discussion
│   └── Abstract（最后写）
├── 5.3 图表制作
├── 5.4 参考文献整理（使用 citation-management skill）
├── 5.5 内部审稿
└── 5.6 修订
```

### 阶段 6：投稿与发表（8-16 周）

```
目标：论文被接收发表
├── 6.1 选择目标期刊
├── 6.2 格式调整
├── 6.3 投稿信撰写
├── 6.4 提交投稿
├── 6.5 审稿意见回复
├── 6.6 修订与重新提交
└── 6.7 校对清样
```

## 团队协作框架

### 角色分工

| 角色 | 职责 | 产出 |
|------|------|------|
| PI (项目负责人) | 总体规划、资源调配、质量把控 | 项目计划、审批 |
| 博士后/研究员 | 实验设计、执行、分析 | 实验方案、分析报告 |
| 研究生 | 日常实验、数据收集 | 实验日志、数据 |
| 技术员 | 设备维护、样本处理 | 技术报告 |
| 统计顾问 | 统计分析支持 | 分析计划、结果 |

### 会议计划

| 会议类型 | 频率 | 参与者 | 目的 |
|---------|------|--------|------|
| 组会 | 每周 | 全员 | 进度汇报、问题讨论 |
| 一对一 | 每两周 | PI + 个人 | 个人进度、指导 |
| 里程碑评审 | 按需 | PI + 核心 | 里程碑完成评审 |
| 论文评审 | 按需 | 作者团队 | 论文质量评审 |

## 数据管理计划

### 数据生命周期

```
收集 → 清洗 → 存储 → 分析 → 归档 → 共享
```

### 数据存储规范

```
项目根目录/
├── data/
│   ├── raw/          # 原始数据（只读）
│   ├── processed/    # 清洗后数据
│   ├── analysis/     # 分析结果
│   └── metadata/     # 数据说明文件
├── scripts/          # 分析脚本
├── docs/             # 文档
├── results/          # 图表结果
└── README.md         # 项目说明
```

### 版本控制建议

1. 代码使用 Git 管理
2. 数据文件使用日期或版本号命名
3. 重要分析结果定期备份
4. 原始数据不可修改（只读权限）

## 风险管理

### 常见风险与应对

| 风险类别 | 具体风险 | 应对策略 |
|---------|---------|---------|
| 人员风险 | 关键人员离职 | 文档化、知识共享 |
| 技术风险 | 方法不可行 | 预实验、备选方案 |
| 数据风险 | 数据丢失 | 多重备份、版本控制 |
| 时间风险 | 进度延误 | 缓冲期、优先级管理 |
| 合规风险 | 伦理问题 | 提前审批、合规审查 |

## 注意事项

1. 科研项目周期长，建议使用项目管理工具跟踪进度
2. 定期与 PI 沟通，及时调整方向
3. 数据管理从项目开始就规划好，避免后期混乱
4. 论文写作建议边做边写（至少 Methods 部分）
5. 保持实验日志的及时性和准确性
